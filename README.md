# Multiplayer PvP Arena

> Roblox multiplayer PvP arena prototype focused on fast-paced ball deflection, sword mechanics, character abilities, and progression.

## 🎮 Project Overview

This project is a multiplayer PvP arena built around a continuously targeting ball.

Players begin each match with three lives. Successfully parrying the ball redirects it toward another valid player while increasing its speed. Players are eliminated after losing all three lives, and the last player remaining wins.

**Current status:** Prototype / Active Development

---

## ⚔️ Core Gameplay

- Three-life match system
- Targeting ball mechanic
- Ball deflection / parry system
- Sword-based deflection
- Increasing ball speed after successful parries
- Player elimination and winner detection
- Character abilities
- Character progression

## 💰 Progression & Economy

The project uses **Vortex Shards** as its primary in-game currency.

Players can earn Vortex Shards through gameplay, including:

- Match wins
- Eliminations
- Weekly quests
- Future events

Vortex Shards are intended for character purchases, sword packs, and future cosmetics.

Characters have independent progression with XP and ability unlocks at different levels.
